# 公开发布审查

本次发布仅包含项目源码、资源、通用构建和测试脚本、许可证、项目说明及 v1.0.0 签名 APK。

审查项目：

- 排除本地 SDK 配置、签名配置、私钥、密码、账号令牌、缓存和构建日志。
- 构建与测试脚本不包含维护者本机的绝对路径、代理地址或端口。
- 文档不包含维护者真实姓名、邮箱、电脑名称或个人设备型号。
- 测试中的坐标为明确标注的合成数据；不分发运动记录、GPX 测试文件或应用私有数据。
- APK 压缩条目及解压内容检查本机路径、个人身份和凭据；应用无网络权限、调试入口或预置轨迹。
- Gradle Wrapper JAR 与官方 SHA-256 校验值比对。
- Git 提交使用项目署名，不使用维护者的全局 Git 姓名或个人邮箱。

公开 APK 的签名证书和校验值属于验证安装包所需的项目信息。证书使用项目名称；不包含私钥。GitHub 仓库所属账号会由平台公开显示。
