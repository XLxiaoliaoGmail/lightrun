# 整公里语音播报

v1.2.2 将语音生成和声音播放分开。系统 TTS 引擎按照系统中文音色把播报文字合成为临时 WAV；合成结束后，轻跑的定位与媒体播放前台服务使用 MediaPlayer 播放。播放持有短期 CPU 唤醒锁，不点亮屏幕。沿用导航语音的音频属性，不强制提高手机音量或切换声音输出设备。

旧实现先更新公里播报进度，再调用 TTS 播放。音频焦点申请失败、通话模式或引擎失败时，这一公里会被消耗且无法重试。新版只在 MediaPlayer 完成回调后更新本次运动的已播报公里数；GPS 回调不会为同一公里重复排队。

语音生成或播放失败最多尝试三次。引擎初始化和合成各有 30 秒响应超时，播放有 45 秒超时；一次播报最多等待约 90 秒。音频被通话或通信占用、焦点暂不可用时稍后重试，不打断通话。跨过新公里时只保留最新播报，暂停、关闭播报、结束运动时取消待播内容。应用异常中断后的恢复仍从当前整公里向后计算，不补播已经过去的公里。

设置页显示最近一次播报的阶段或结果，例如正在生成、正在播放、播放完成、媒体音量为零、失败未播完或已停止。结果只存本机，不含 GPS 坐标、轨迹、账号或手机标识，不上传。临时 WAV 在正常完成、取消或失败后删除；进程意外退出可能留下私有缓存，由系统缓存管理回收。

播放完成回调只能确认播放管线已结束，不能证明人耳听到了声音。媒体音量、蓝牙或其他输出设备、厂商省电限制及系统引擎是否联网仍取决于手机。无法仅凭运动截图确认某台手机漏播的具体原因，应结合开关、系统试听、最近播报结果和实际锁屏试跑判断。

实现见 `VoiceCoach.java`、`TrackingService.java` 和 `RunSession.java`。测试引擎只在测试 APK 中，以合成音和失败注入验证状态及回调，不代表厂商中文引擎。
