- 标准、中文三字母代码、旧式接口、延迟/缺失列表、未安装标记和在线音色等七类测试引擎，均沿用系统选择的中文音色，不强制 embeddedTts；保留原 GPS、锁屏、暂停、恢复、步数持久化、历史和 GPX 验证。
- 55 项核心断言、正式 release 构建与 Android Lint 通过。
- 正式签名 APK 联网验证：手动/自动检查及每日间隔，真实 Gitee 附件下载、进度条、取消清理、失败后重试；下载完成 100%，安装包校验成功。同包同版本但不同签名的 APK，即使哈希匹配也被拒绝。
- 正式包验证首次安装授权引导，授权后返回打开 Android 安装确认页，无浏览器跳转。
- v1.1.2 覆盖升级保留旧格式记录；签名证书与原版本一致，APK v2 验证通过。
- 原有正式包权限与界面流程通过 12 项断言；系统文档选择器实际保存 GPX 1.1 并解析通过。

测试语音引擎生成测试音，不代表厂商的真实中文发音。模拟器无法替代各手机的户外计步、长时间耗电、后台策略及安装限制验证。当前下载不支持进程重启恢复、断点续传或签名密钥轮换。
## v1.1.2

修正“未安装离线中文语音”的过度判断。默认模式识别中文三字母语言代码，保留可识别的系统离线音色，兼容延迟返回音色列表和旧式 embeddedTts 接口，并在一个音色不可用时尝试其他离线音色。增加用户主动开启的系统音色兼容模式；此模式不宣称强制离线，界面和隐私说明明确提示系统引擎可能联网。

- Android 8 / 15 / 16（API 26 / 35 / 36）模拟器分别通过 76 项设备断言。
- 测试覆盖标准音色、三字母中文代码、旧式离线接口、延迟列表、不可用音色、缺失元数据、仅在线音色、未安装标记及兼容模式。默认模式拒绝未验证的在线或缺失音色，不发生静默降级。
- 55 项核心断言、正式 release 构建与 Android Lint 通过。
- 正式 APK 签名证书与已有版本一致，v1.1.1 覆盖升级后旧格式记录仍可读取。
- 正式 APK 原有界面与权限流程通过 12 项断言；新增设置开关、偏好保存与兼容试听状态已通过实际界面操作验证。
- 公开源码无签名配置重新构建成功，9 个 APK 功能条目与正式签名包一致。

测试使用合成音引擎，并非厂商引擎或真实中文发音。无法仅凭系统设置截图确认具体厂商返回的数据，实际手机仍需用新版试听；系统音色兼容模式建议关闭 Wi-Fi 和移动数据后确认。
