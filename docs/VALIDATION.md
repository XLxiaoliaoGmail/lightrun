# v1.0.0 验证记录

发布 APK 为已测试的 v1.0.0 原始签名产物，未替换签名或重打包。校验值见 `releases/v1.0.0/SHA256SUMS`。

| 验证 | 结果 |
| --- | --- |
| 纯 Java 轨迹过滤、距离、分段、计时与格式 | 30 项断言通过 |
| Android 8.0 / API 26 模拟器 | 23 项设备断言通过 |
| Android 15 / API 35 模拟器 | 23 项设备断言通过 |
| Android 16 / API 36 模拟器 | 23 项设备断言通过 |

| release 构建与 Android Lint | 通过，0 个错误 |
| APK v2 签名 | 验证通过 |

UI 验证覆盖定位拒绝、仅模糊位置、GPS 关闭、通知拒绝、开跑、强制停止恢复、历史记录和导出。设备测试与文件导出均使用合成 GPS 点，不是真实用户的运动轨迹。

模拟器验证不能替代各厂商手机的户外实跑与长时间耗电测试。当前未宣称所有手机后台策略均已验证。
