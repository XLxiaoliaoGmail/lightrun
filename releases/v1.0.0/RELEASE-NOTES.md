# 轻跑 v1.0.0

首次公开发布。支持 Android 8.0 及以上。

包含 GPS 跑步轨迹、时长、距离、平均配速、暂停/继续、锁屏记录、历史记录、删除和 GPX 导出。无需账号、无广告、无联网权限；使用离线轨迹线，不包含街道底图。

APK 已签名，可直接安装。测试覆盖 Android API 26、35、36 模拟器以及最终 release 包的权限与恢复流程。首次安装后请允许精确位置，并在自己的手机上检查锁屏记录。
